## 2) Random Word Generator

A web-based tool for randomly selecting 30 words from a predefined list of 60 candidate words.

**How to use:**
1. Open the Random Word Generator using the link below.
2. Click the **Generate 30 Random Words** button.
3. The tool will randomly select 30 unique words from the 60 candidate words.
4. The selected words are displayed in random order.
5. Use the Copy or Download CSV option to save the selection.

**Access the tool:** [Random Word Generator](https://ramaraju301.github.io/Development-of-a-Campus-Based-Indian-Normative-Database-of-Word-Associations-and-Category-Responses/)
